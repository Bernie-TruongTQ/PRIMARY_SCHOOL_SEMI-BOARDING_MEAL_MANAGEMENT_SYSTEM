# Phase 05 — UI/UX Wireframes & Mockups

## What is this?

Every screen in this phase is derived from the Screen Inventory in [Phase 04](../04-information-architecture/screen-inventory.md). No screen was designed without a corresponding Use Case and Task Flow.

Screen derivation path:
```
Use Case (Phase 03)
      ↓
Task Flow (Phase 04)
      ↓
Screen Inventory Entry
      ↓
Wireframe (structural layout)
      ↓
Mockup (visual design)
```
